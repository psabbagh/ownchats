# For AI agents

If you are helping someone set up, run, debug or update their own copy of OwnChats, follow [docs/guide-for-ai-agents.md](docs/guide-for-ai-agents.md). It has the ground rules (the person types every secret; ask before anything that messages a real person or deploys), what Meta's screens actually show, the problems found on the first real run and their fixes, database queries for diagnosing, and how to update a copy made with the Deploy button.

If you are changing OwnChats itself, read [docs/design.md](docs/design.md) first and update it when a decision changes. `npm run check` and `npm test` must pass.
